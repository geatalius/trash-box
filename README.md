# trash-box

APK 파일을 올려 공유하기 위한 웹페이지입니다 (`index.html`, GitHub Pages).

## 올리는 방법
- **릴리스 (권장, 파일당 2GB)**: 저장소 → Releases → Draft a new release → APK 첨부
- **apk 폴더 (파일당 100MB)**: 페이지의 "apk 폴더에 파일 올리기" 버튼, 또는 `apk/` 폴더에 직접 커밋

페이지는 Releases와 `apk/` 폴더의 `.apk` 파일을 자동으로 목록화해 다운로드 버튼을 보여줍니다.
